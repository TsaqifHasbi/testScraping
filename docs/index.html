Tentang Proyek Ini

Aplikasi/skrip ini dibangun untuk keperluan penelitian akademik non-komersial (Tugas Akhir/Skripsi) oleh [ISI NAMA ANDA], mahasiswa [ISI PROGRAM STUDI], [ISI NAMA KAMPUS]. Penelitian ini menganalisis sentimen dan pola jaringan sosial publik terkait program pemerintah (mis. Sekolah Rakyat) di berbagai platform media sosial, termasuk Threads, untuk tujuan riset opini publik akademik.

Data yang Dikumpulkan

Sistem ini hanya mengambil konten publik melalui Threads API (Keyword Search), berupa:

  • Teks postingan publik dan tagar/topik terkait
  • Nama pengguna publik penulis postingan
  • Metrik keterlibatan publik (like, reply, repost, quote)
  • Waktu unggah (timestamp)

Sistem tidak mengakses pesan pribadi, kredensial akun pengguna lain, maupun data non-publik apa pun.

Bagaimana Data Digunakan

  • Semata untuk analisis sentimen dan Social Network Analysis (SNA) dalam lingkup penelitian akademik.
  • Hasil dipublikasikan dalam bentuk agregat/statistik (grafik, metrik, model) pada dokumen Tugas Akhir, bukan dalam bentuk data mentah yang dapat diidentifikasi ke individu tertentu.
  • Tidak dijual, disewakan, atau dibagikan ke pihak ketiga untuk tujuan komersial.

Penyimpanan Data

Data disimpan secara lokal/aman oleh peneliti selama masa penelitian berlangsung, dan akan dihapus paling lambat [ISI DURASI, mis. 6 bulan setelah sidang TA selesai].
